# v0.1.0-alpha.1

Developer preview of Commons Suite, an Apache-2.0 self-hosted productivity workspace.

- Collaborative rich-text documents with durable Yjs state.
- Basic spreadsheets with arithmetic, references, SUM ranges, and XLSX export.
- Simple title/body presentations with PPTX export.
- Shared folders, member permissions, editing leases, and content history.
- Basic DOCX/XLSX import with explicit compatibility warnings.

This release is intended for private evaluation with non-sensitive data. It has no Office parity, production scale, SSO, or compliance guarantee. See README and docs/SECURITY.md for limitations and the known moderate upstream advisory.
